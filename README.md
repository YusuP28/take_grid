# Take Grid

Aplikasi grid foto untuk Android — gabungkan beberapa foto jadi satu dengan template grid, border, filter, stiker, dan teks.

## Fitur (roadmap)

- Grid template (2x2, 3x3, 2x1, dll)
- Pilih foto dari galeri
- Atur border/gap
- Pilih rasio (1:1, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9)
- Background color/pattern
- Filter (brightness/contrast/saturation)
- Stiker + emoji
- Teks overlay (font, color, drag)
- Export JPG/PNG dengan quality
- Template favorit
- Share ke aplikasi lain

## Stack

- Flutter 3.24.5
- Provider
- sqflite (history)
- image (manipulasi)
- CustomPainter (grid rendering)

## Build

Build otomatis via GitHub Actions. Lihat tab Actions / Releases.
